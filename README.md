# yun · 云播放器

粘贴磁力链接 → 云端下载 → 网页直接播放。

**界面就三样东西：一个链接输入口、一个播放器、一份播放记录。** 不需要任何网盘账号，文件存在 VPS 硬盘上，下载完点开就看。基于 [AList](https://github.com/alist-org/alist) + Aria2 + ffmpeg + 自带极简前端页，Docker 一键部署。

**什么格式都能在浏览器里播。** MKV、H.265/HEVC、10bit、AC3/DTS 这些浏览器原生放不出来的，服务端会自动实时转码成 HLS 喂给播放器；内嵌字幕和外挂字幕自动转 WebVTT，多音轨（国语/粤语/原声）网页里直接切。

## 使用就三步

### 第 1 步 · 安装（VPS 上执行一条命令）

```bash
curl -fsSL https://raw.githubusercontent.com/a317634186/yun/main/install.sh | bash
```

全自动，不用输入任何东西。首次安装会构建转码服务镜像，比以前多花 1-3 分钟。装完屏幕上会显示**网址、账号 admin、密码**，截图保存。

> 记得在云服务器控制台的**安全组**放行 `5244` 端口，否则网页打不开。
> 提示 `Could not resolve host`（DNS 问题）先执行：
> ```bash
> systemctl disable --now systemd-resolved 2>/dev/null; rm -f /etc/resolv.conf; printf 'nameserver 1.1.1.1\nnameserver 8.8.8.8\n' > /etc/resolv.conf
> ```

### 第 2 步 · 打开网页，输入密码

浏览器打开 `http://你的VPS_IP:5244`，就是登录页：账号 `admin` + 安装时显示的密码（浏览器会记住，下次自动登录）。

### 第 3 步 · 粘链接 → 等下载 → 直接看

1. 顶部输入框**粘贴磁力链接**（`magnet:?xt=...` 或 .torrent 文件的下载链接）→ 点「添加下载」
2. 「下载列表」实时显示进度条（内置高速下载：64 分片、16 连接、自动 tracker）
3. 点任务的「展开文件」→ 对着视频点「▶ 播放」，**下载中也能先看**
4. 「播放记录」自动记录看到哪了，下次点击**从上次位置继续**；看完的标 ✅

## 在线播放是怎么做到的

点播放后，服务端先探测这个文件浏览器到底能不能吃，然后二选一：

| 模式 | 什么时候用 | 特点 |
|---|---|---|
| **原画直连** | mp4/webm 容器 + H.264/VP9/AV1 + AAC/MP3/Opus | 零 CPU 占用、随便拖进度条、下载中就能看 |
| **实时转码** | 其余全部情况（MKV / H.265 / 10bit / AC3 / DTS / AVI / TS…） | 转成 HLS 喂给播放器，同样能拖进度条，顺带把带宽压下来 |

播放器上方会显示当前用的是哪种模式和原因，右边可以手动切**清晰度 / 音轨 / 字幕**。直连播不动时会自动降级去转码，不用你自己判断格式。

转码的实现是**每个分片独立起一个 ffmpeg**（`-ss` 精确定位 + `-output_ts_offset` 拼回全局时间轴），所以：

- 拖进度条到片尾不用等前面转完，点哪播哪
- 转好的分片会缓存，回看和二次观看不重复烧 CPU
- 播放中断/刷新页面不会丢进度

**转码要吃 CPU。** 安装时会按 CPU 核数自动配一套参数（1 核 → 480p、2-7 核 → 720p、8 核以上 → 1080p），之后可以用 `bash menu.sh` 菜单 `10` 随时调。卡顿就把清晰度调低一档，觉得糊就往上调。

## 存储与流量说明

- 容量上限 = VPS 硬盘大小（`df -h` 查看）
- **播放走 VPS 流量**：原画直连看 10GB 电影约耗 10GB 流量；走转码（比如降到 720p）通常能省下一半以上
- **自动清理由服务端常驻执行**：下载文件默认保留 1 小时，磁盘占用超过 90% 会提前删最旧的，**正在看的文件不会被删**。网页关掉照样生效（旧版本的清理写在前端 JS 里，不开网页就不执行）
- 保留时长、磁盘水位、缓存上限都可以用菜单 `10` 改，`RETENTION_HOURS=0` 就是永不自动删

## 安全说明

- 视频直链 `/d/...` 和目录列表 `/ls/...` 都需要**登录后下发的签名票据**才能访问（HMAC 签名，默认 12 小时有效），不再是知道 IP 就能列目录、拖走文件
- 想关掉这层校验（不建议）：`.env` 里设 `AUTH_ENFORCE=0`
- 仍然建议只在自己用的机器上开放端口，或者套一层 HTTPS 反代

## 可选功能

- **挂载网盘扩容**：VPS 磁盘不够时，访问 `http://IP:5244/@login` 打开原版 AList 管理后台 → 存储 → 添加 OneDrive / Google Drive
- **硬件加速**：机器有核显/独显时，`.env` 里设 `HWACCEL=vaapi`（或 `qsv` / `cuda`）与 `VIDEO_ENCODER=h264_vaapi`，转码能力可以翻好几倍

## 常见问题

| 问题 | 处理 |
|---|---|
| 网页打不开 | 云厂商安全组放行 5244 端口；`bash menu.sh` 选 7 看日志 |
| 登录一直转圈/失败 | `bash menu.sh` 选 8 重置密码后重试 |
| 磁力下载没速度 | 种子冷门，属正常现象；换热门种子测试 |
| 画面卡一下一下的（转码模式） | CPU 不够。菜单 `10` 把清晰度降到 480p、画质调到 26 |
| 提示「转码超时」 | 同上，降清晰度；或改用 `X264_PRESET=ultrafast` |
| 有画面没声音 | 换个音轨试试；日志里看 ffmpeg 报错 |
| 字幕不显示 | 只支持文本字幕（SRT/ASS）；蓝光原盘的 PGS 图形字幕转不了，不会出现在列表里 |
| 下载中播放报错 | BT 是乱序下载的，前面的数据可能还没到。等进度再多一点重试 |
| 401 / 一直提示重新点击播放 | 票据过期，重新点一次播放即可 |
| 视频列表全空 | 转码服务没起来（目录列表要它鉴权）。`bash menu.sh` 选 4 看状态 |
| VPS 磁盘满 | 网页里删除看完的文件，或把 `RETENTION_HOURS` 调小 |

## 目录结构

```
yun/
├── install.sh            # 一键安装脚本
├── menu.sh               # 管理菜单
├── web/index.html        # 播放器前端页面（输入框+播放器+记录）
├── caster/               # 播放服务：探测 / 转码 / 字幕 / 鉴权 / 清理
│   ├── app.py            #   纯标准库 HTTP 服务，调 ffmpeg 干活
│   └── Dockerfile        #   python + ffmpeg + 内置 hls.js
├── nginx.conf            # 前端页面 + 接口/视频反代 + 直链鉴权
├── docker-compose.yml    # alist + caster + web 三个容器编排
├── .env.example          # 配置模板（端口、转码参数、清理策略）
├── data/                 # AList 数据（运行时生成）
├── downloads/            # 下载存放目录（运行时生成）
└── cache/                # 转码分片缓存（运行时生成，可随时删）
```
